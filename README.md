# Flat Finder 🏠

Aplicação web para gestão de imóveis para arrendamento, desenvolvida em **JavaScript puro**, sem frameworks.

🔗 Demo ao vivo: https://clafernandes.github.io/flat-finder/login.html

## 📋 Sobre o Projeto

O Flat Finder simula uma plataforma de arrendamento de imóveis, permitindo autenticação de utilizadores, gestão completa de anúncios e organização de favoritos, tudo com persistência local no navegador.

## 🚀 Funcionalidades

- **Autenticação**: registo e login por email
- **CRUD de imóveis**: criar, editar, listar e remover anúncios
- **Filtros**: pesquisa por cidade, preço e área
- **Favoritos**: sistema de imóveis favoritos por utilizador
- **Perfil editável**: cada utilizador gere os seus próprios dados
- **Privacidade de dados**: cada utilizador vê apenas os seus próprios imóveis

## 🛠️ Tecnologias

- HTML5
- CSS3 (Flexbox)
- JavaScript (vanilla, sem frameworks)
- `localStorage` para persistência de dados
- `crypto.randomUUID()` para geração de IDs únicos

## 🏗️ Arquitetura

- Estrutura modular por página, com injeção dinâmica de header e footer
- Sem backend — todos os dados são geridos e persistidos no lado do cliente
